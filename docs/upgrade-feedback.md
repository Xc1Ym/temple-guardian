# 升级提示与属性面板修复

2026-10-13，按用户指出的升级提示不明显问题更新。

- 桌面原升级区域保留原版箭头素材，使用可点击的横排“升级至 N 级”，直接显示金钱和神迹费用。鼠标悬停或键盘聚焦时，显示等级、攻击力、攻击速度、耐久／生命及射程的前后变化。
- 手机在地图下方显示升级预览和明确的升级按钮。资源不足时显示还差多少金钱或神迹；最高等级、暂停和未选择设施均给出说明。
- 成功后显示升级前后等级、实际费用和属性变化。连续通知会重置显示时间，避免被之前的提示提前隐藏。空格聚焦升级按钮时执行该按钮，不会同时开始敌人波次。
- 升级仍执行原版按钮脚本。保留购买倍率、取整、金钱门槛和神迹消耗；原版折扣下的金钱门槛与实际扣费不同时，提示同时说明两者。

验证还发现，原属性面板每 5 帧跳回首帧刷新。旧原生实现跳帧时无条件重建所有静态子对象，导致升级区的设施引用丢失。现在保留在两个帧中连续存在的实例及其脚本属性；确实移除、替换或重新放置的实例仍重新创建。回归检查覆盖等待面板刷新后升级、重复升级、资源不足和满级。

原版弩箭塔的预览字段写“攻击速度 11”，而实际二级初始化脚本赋值为 12；三级同样有预览与实际不一致。新的升级预览从各等级原始初始化脚本提取实际速度，属性面板同步显示该值，升级后实际数值保持原逻辑。该映射可由 `tools/export-game.py` 重复生成，不修改原脚本或战斗数值。
