# 本局修改器

将鼠标放在页面顶部中央、距顶部约 24～52 像素的棕色区域，隐藏的“修改器”按钮会显现，点击打开。入口固定在页面顶部，不随游戏画面的居中位置下移。平时入口与背景融合，只在鼠标悬停时显现。英文输入模式下，连续输入 `godmode` 也会打开，无需回车、不区分大小写。输入框、中文输入法组合过程和 Ctrl／Command／Alt 快捷键不会触发暗号；字符间隔超过五秒会重新开始识别。

面板保留原版舞台和操作。战斗中打开时暂停游戏和准备倒计时；关闭恢复原先的暂停状态。后台关闭面板后仍需从原版暂停窗口主动继续。按钮和暗号进入同一个面板。

## 功能

| 项目 | 效果和范围 |
| --- | --- |
| 金钱、神迹、总分 | 0～1,000,000,000 整数；批量应用前校验全部输入，错误时不修改任何数值。可一键将金钱和神迹设为 999999。 |
| 神殿耐久和上限 | 当前耐久 1～上限；上限 1～1,000,000。支持恢复已损毁神殿；失败结算后通过跳关重试。 |
| 资源锁定 | 固定为金钱／神迹输入值，实际购买扣费、奖励及敌人对神迹的扣减都不会改变该值；关闭锁定保留最后锁定数值。 |
| 神殿、设施无敌 | 伤害判定使用满耐久；设施在耐久制中可持续攻击。关闭时恢复完整耐久，避免此前被拦截的伤害导致突然损毁。 |
| 免费建造、升级、研究 | 实际价格判断与资源扣除均免费，零资源也可操作；出售和击杀奖励沿用原规则。 |
| 一击必杀 | 已初始化敌人受到实际伤害后耐久归零；护盾不阻挡伤害。敌人继续通过原版死亡、奖励和计分流程结算。 |
| 解锁设施 | 提前开放终章神龙像，并解除神龙像与烈焰坛数量限制；保留草地／道路、入口和神殿距离限制。关闭时按实际在场设施重新统计数量。 |
| 准备倒计时冻结 | 限时制与耐久制停留在准备阶段，仍可手动按空格开始。 |
| 攻击、射程、攻击加速 | 分别为 1～1000、1～50、1～100 倍，允许小数；作用到实际攻击、目标搜索和冷却。攻击加速受原版发射动画长度限制。射程圆同步更新。 |
| 敌人速度 | 0～1 倍，0 时停止移动；关闭恢复原本的移动速度和特殊能力基础速度。 |
| 游戏速度 | 0.25～8 倍，增加／减少每秒执行的固定逻辑帧，单帧仍为原版 1/28 秒。 |
| 研究 | 五项原版研究均可设置 0～6 级或一键满级，现有／新设施使用相同研究公式，耐久制消耗计数同步更新。 |
| 一键操作 | 恢复神殿和设施耐久；现有设施升级到原版最高等级；清除草地障碍，保留道路和已有设施；消灭本关全部敌人，含尚未进入地图的敌人。 |
| 跳关 | 1～50 关；清除当前敌人、弹道、特效和旧结算窗口，保留地图、资源、研究和设施。进入目标关准备阶段，返回游戏后按空格开始。神殿损毁时自动修复。 |

持续加持只对当前一局生效，不写入本地设置。退出本局／返回主菜单后自动恢复关闭和 1 倍速度。关卡切换时加持保留。手动修改的数值、研究、设施等级属于本局游戏状态，关闭面板或“关闭全部加持”不会回滚；本机排行榜也会保存修改后的成绩。

## 实现与验证

`src/trainer.ts` 提供独立的修改命令与每局选项，通过原生运行时的读写入口拦截价格、伤害与移动；原始 AS2 脚本和生成模块不改写。未开启加持时运行时读写拦截器为空，原版公式和执行顺序保持原样。界面和暗号识别分别位于 `src/trainer-ui.ts`、`src/main.ts`。

回归覆盖正常状态对照、原子输入校验、零资源真实交易、资源锁定、实际弹丸伤害和发射频率、射程与命中、护盾、耐久制、实际敌人移动、两种倒计时、五项研究、第一章建造三个神龙像、障碍、退出重置及第 1／30／31／50 关的清关奖励和结算。生产字体重新生成以覆盖修改器中文。浏览器另外检查隐藏入口、暗号、暂停／返回、原版 HUD 和字段回显。
